## Breaking changes

- The `models` config key is retired. The relay routes every Claude request to one
  of two slots: a name matching `opusModel` or `gptModel` goes there, any other name
  containing `opus` goes to `opusModel`, and the rest to `gptModel`. A `models:`
  line an earlier release wrote stays in `config.yaml` and has no effect; it is
  safe to delete. Codex is offered the two slots only.
- `copilot-relay status --json` no longer has `config.models`.
- Every command's human output is redesigned: a heading, marked rows and tables
  within 80 columns. Scripts should read the exit codes, which are unchanged, or
  `--json` where a command has it. `replay` no longer prints the bare verdict as
  its first line or `key=value` lines; it prints a heading, a marked verdict, the
  request, a table of exchanges and every differing path.
- `GET /v1/models` lists the two slots only.
- Fresh installs default `gptModel` to `gpt-6.2-astra`. An existing `gptModel`
  value is kept.

## Measurements

Median of 5 alternating runs after one warm-up, same machine (Apple M3 Pro,
Node 26.13.1), same inputs: 2,000 mocked `POST /v1/messages` Claude Code-like turns
against a local mock upstream. Every reply is checked for its status, text and
exact usage; each heap sample waits for every request's trace and flushes logs
first. Lower is better.

| Metric | v0.6.2 | v0.7.1 | v0.8.0 |
| --- | ---: | ---: | ---: |
| Mean time per request | 560 µs | 535 µs | 543 µs |
| Heap after GC | 46.0 MiB | 40.7 MiB | 19.0 MiB |
| Resident memory | 239.1 MiB | 253.9 MiB | 154.1 MiB |
| Routing decision | 70 ns | 160 ns | 85 ns |
| `--help` wall time | 0.15 s | 0.15 s | 0.15 s |
| `--help` peak memory | 70.0 MiB | 70.0 MiB | 66.8 MiB |

Each upstream operation now owns one deadline and releases it when its body
settles, so a finished request no longer stays reachable for the upstream timeout
(180 s by default), including one waiting on a token refresh. In the heap
regression test, v0.7.1 kept all 20 sampled finished requests reachable and grew
about 22.8 MB over 2,000 requests; v0.8.0 keeps none and stays under 1 MiB.
